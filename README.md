<a id="start" name="start"></a>
## 🚀 开始使用

打开站点后，首页有两张卡片：**游逸旅闻**、**尘歌壶赠礼套装**。点进去就是对应工具，左上角 ☰ 可以随时切换到另一个。

**不需要登录，不需要填任何个人信息，打开就能用。**

| 你想要 | 怎么做 |
|---|---|
| 记录哪些旅闻做过了 | 进「游逸旅闻」，点卡片 |
| 查某个角色有哪些旅闻 | 进「游逸旅闻」，搜索角色名 |
| 记录角色送过哪些套装 | 进「尘歌壶赠礼套装」，先勾自己拥有的角色 |
| 换手机、换浏览器 | 先导出存档，到新设备导入（见[数据保存](#save)） |
| 夜间使用 | 点右上角图标切换深浅色 |

首次打开会自动跟随系统主题，之后按你的选择记住。

<a id="tales" name="tales"></a>
## 📖 游逸旅闻

### 界面

顶部三行常驻，滚动只作用于下方的旅闻列表：

1. **搜索框 + 完成计数** —— 输入角色名或旅闻名即时筛选，右侧显示「已完成 X / 总数」
2. **三个筛选下拉** —— 版本 / 状态 / 类型
3. **UID + 导出导入** —— UID 选填，只用于存档文件名

### 三种筛选怎么用

| 筛选 | 选项 | 说明 |
|---|---|---|
| 版本 | 全部版本 + 各版本号 | 按实装版本筛 |
| 状态 | 全部 / 已完成 / 未完成 | 按你的进度筛 |
| 类型 | 全部 / 正常 / 隐藏 | 「隐藏」指游戏里不显示的隐藏成就 |

三个筛选可以叠加，和搜索框同时生效。

### 标记完成

点任意一张卡片即可切换完成状态，右上角进度实时更新，**自动保存，不需要手动提交**。

- 已完成的卡片底色变暗、整体变淡、右侧出现勾选
- **标题是红色**的表示该旅闻属于隐藏成就
- 卡片下方金色文字是地点 / 触发条件 / 前置旅闻

### 底部按钮

「清空全部记录」固定在页面最底部，**不会和日常操作挨着**，防止误触。点击后会二次确认。

> ⚠️ 清空前建议先「导出」备份，**清空不可撤销**。

<a id="giftset" name="giftset"></a>
## 🎁 尘歌壶赠礼套装

页面自上而下三块，都可以点标题折叠。

### 一、我的角色

先在这里勾选**你已经拥有的角色**（点一下切换，选中的会高亮）。这是后面一切计算的基础。

- 默认按实装顺序倒序，最新的角色在前
- 支持搜索
- 勾选后这一块会自动收起，点标题可再展开

### 二、推荐套装

根据你的角色和进度自动算出的「最值得先做」的套装，**最多 5 个**。

排序规则：
1. 你拥有但还没送完的角色越多，越靠前
2. 同样多的，按「你拥有的角色占该套装总角色数的比例」高的在前
3. 再相同则按套装编号

点卡片就地展开，展开状态和下面的「全部套装」**互相同步** —— 在一处展开，另一处也会展开。

### 三、全部套装

单列手风琴列表，每张卡显示缩略图、名称、地区 · 室内外、以及进度。

**四种进度状态**：

| 显示 | 含义 |
|---|---|
| `3 / 5` | 你拥有的 5 个角色里已送完 3 个 |
| 未拥有角色 | 这个套装需要的角色你一个都没有 |
| 已完成 | 你拥有该套装全部角色，且全部送完 |
| 已送完 | 你拥有的角色都送完了，但还有角色没拥有 |

已完成 / 已送完的套装配深色描边并整体变淡。

展开后点角色格切换完成状态。**点未拥有的角色会提示你先去上面勾选。**

### 筛选与搜索

支持按套装名 / 角色名搜索，以及地区、室内外、状态三个下拉筛选。

筛选里的「未完成」只包含**有角色但没送完**的套装，不含「未拥有角色」的那些。

### 底部按钮

「重置全部数据」在页尾固定区，会清空拥有的角色和所有完成记录，需二次确认。

<a id="save" name="save"></a>
## 💾 数据保存

### 数据存在哪

**全部存在你这台设备的浏览器里**（`localStorage`），不会上传到任何服务器，也不会跨设备同步。

| 内容 | 存储位置 |
|---|---|
| 游逸旅闻 · 完成记录 | 浏览器本地存储（`genshin_travelers_tales_completed_v2`） |
| 游逸旅闻 · UID | 浏览器本地存储（`genshin_travelers_tales_uid_v1`） |
| 赠礼套装 · 我拥有的角色 | 浏览器本地存储（`genshin_homeworld_gift_sets_owned_v1`） |
| 赠礼套装 · 送出记录 | 浏览器本地存储（`genshin_homeworld_gift_sets_completed_v1`） |
| 赠礼套装 · UID | 浏览器本地存储（`genshin_homeworld_gift_sets_uid_v1`） |
| 两个编辑器的草稿 | 浏览器本地存储（`…_editor_draft_v1`） |
| 深浅色选择 | 浏览器本地存储（`adventurer-handbook-theme`） |

**用无痕模式、清浏览器数据、换设备，记录都会没。** 唯一的安全网是导出存档 —— 攒了进度就顺手导一份。

### 导出与导入

两个查询页的工具栏右侧都有**导出 / 导入**：

| 动作 | 结果 |
|---|---|
| 导出 | 下载一个 JSON，文件名带 UID 和日期（如 `游逸旅闻存档记录-100000000-20261108.json`） |
| 导入 | 选一个之前导出的 JSON |

- 导出的是**你的进度**（做过的旅闻 / 勾选的角色 + 送出记录 + UID），不是游戏数据。
- **导入是覆盖**：当前进度会被文件里的内容整体替换，不是合并 —— 同机想留旧进度就先导一份再导新的。
- 游逸旅闻读得下**老格式**存档（早期版本导出的文件也能导入）；格式不对会明确报错，不会写坏进度。
- 两个工具各管一份存档，互不相通。
- 换手机：旧设备导出 → 新设备打开站点 → 导入。

> ⚠️ 页尾的「清空全部记录」/「重置全部数据」**立即生效、不可撤销**（有二次确认），动手前先导出。

### 游戏数据从哪来

- **旅闻 / 套装数据**在仓库里：`public/data/tales.js`、`public/data/gift-set.js`，由两个编辑器维护（见[常见问题](#faq)）。
- **角色头像 / 名片 / 立绘**来自主仓库 [genshin-guide](https://grilled-tiger-fish-lw.github.io/genshin-guide/) 的**图片字典**，运行时才去取；取不到只是没图，页面照常能用。

<a id="faq" name="faq"></a>
## ❓ 常见问题

**记录会被上传吗？**
不会。没有服务端，全部在你这台设备的浏览器里（见[数据保存](#save)）。

**换手机 / 换浏览器，进度还在吗？**
不在。先在旧设备**导出存档**，再到新设备**导入**。

**清空浏览器数据、用无痕模式之后进度没了？**
本地存储跟着清空，找不回来 —— 只能靠之前导出的 JSON 恢复。

**改了数据（旅闻 / 套装），站点上没变？**
两个编辑器改完点「导出」→ 导出得到的文件名**已经就是** `tales.js` / `gift-set.js`，直接覆盖 `public/data/` 下的同名文件 → 提交，等 Actions 部署完（一两分钟）再刷新。

**编辑器上写着「尚未导出」是什么意思？**
你的改动只在草稿里，还没导出成文件。草稿自动存在本机，关掉页面再回来还在；**导出成功才算落地**。

**首页卡片 / 角色格子上没图？**
图来自主仓库的图片字典。取不到时页面不会报错，只是图空着（名字、进度都正常）—— 多半是网络或主仓库正在部署，刷新一下；一直空就是那边的事。

**「隐藏」是什么意思？**
游戏里不显示的隐藏成就。旅闻卡片标题是红色，用「类型 → 隐藏」能单独挑出来。

**为什么每次打开颜色不一样？**
首次跟随系统主题，之后按你手动选的记住。

## 🗂️ 项目结构

    adventurer-handbook/
    ├── index.html                    入口（主题预置 + 加载守卫）
    ├── src/
    │   ├── components/               可复用控件（按钮 / 输入 / 抽屉 / 弹窗 / 页签…）
    │   ├── composables/              主题 / 通知队列 / 数据加载
    │   ├── icons/                    UI 图标（内联 SVG）
    │   ├── styles/                   设计令牌 + 全局基线
    │   └── views/                    页面（首页 / 旅闻 / 套装 / 两个编辑器）
    ├── public/
    │   └── data/                     游戏数据（tales.js / gift-set.js，运行时加载）
    └── .github/workflows/            构建检查 + 部署
