## 🚀 开始使用

打开站点后，首页有两张卡片：**游逸旅闻**、**尘歌壶赠礼套装**。点进去就是对应工具，左上角 ☰ 可以随时切换到另一个。

**不需要登录，不需要填任何个人信息，打开就能用。**

| 你想要 | 怎么做 |
|---|---|
| 记录哪些旅闻做过了 | 进「游逸旅闻」，点卡片 |
| 查某个角色有哪些旅闻 | 进「游逸旅闻」，搜索角色名 |
| 记录角色送过哪些套装 | 进「尘歌壶赠礼套装」，先勾自己拥有的角色 |
| 换手机、换浏览器 | 先导出存档，到新设备导入（见[数据保存](#save)） |
| 夜间使用 | 点右上角图标切换深浅色 |

首次打开会自动跟随系统主题，之后按你的选择记住。

<a id="tales" name="tales"></a>
## 📖 游逸旅闻

### 界面

顶部三行常驻，滚动只作用于下方的旅闻列表：

1. **搜索框 + 完成计数** —— 输入角色名或旅闻名即时筛选，右侧显示「已完成 X / 总数」
2. **三个筛选下拉** —— 版本 / 状态 / 类型
3. **UID + 导出导入** —— UID 选填，只用于存档文件名

### 三种筛选怎么用

| 筛选 | 选项 | 说明 |
|---|---|---|
| 版本 | 全部版本 + 各版本号 | 按实装版本筛 |
| 状态 | 全部 / 已完成 / 未完成 | 按你的进度筛 |
| 类型 | 全部 / 正常 / 隐藏 | 「隐藏」指游戏里不显示的隐藏成就 |

三个筛选可以叠加，和搜索框同时生效。

### 标记完成

点任意一张卡片即可切换完成状态，右上角进度实时更新，**自动保存，不需要手动提交**。

- 已完成的卡片底色变暗、整体变淡、右侧出现勾选
- **标题是红色**的表示该旅闻属于隐藏成就
- 卡片下方金色文字是地点 / 触发条件 / 前置旅闻

### 底部按钮

「清空全部记录」固定在页面最底部，**不会和日常操作挨着**，防止误触。点击后会二次确认。

> ⚠️ 清空前建议先「导出」备份，**清空不可撤销**。

<a id="giftset" name="giftset"></a>
## 🎁 尘歌壶赠礼套装

页面自上而下三块，都可以点标题折叠。

### 一、我的角色

先在这里勾选**你已经拥有的角色**（点一下切换，选中的会高亮）。这是后面一切计算的基础。

- 默认按实装顺序倒序，最新的角色在前
- 支持搜索
- 勾选后这一块会自动收起，点标题可再展开

### 二、推荐套装

根据你的角色和进度自动算出的「最值得先做」的套装，**最多 5 个**。

排序规则：
1. 你拥有但还没送完的角色越多，越靠前
2. 同样多的，按「你拥有的角色占该套装总角色数的比例」高的在前
3. 再相同则按套装编号

点卡片就地展开，展开状态和下面的「全部套装」**互相同步** —— 在一处展开，另一处也会展开。

### 三、全部套装

单列手风琴列表，每张卡显示缩略图、名称、地区 · 室内外、以及进度。

**四种进度状态**：

| 显示 | 含义 |
|---|---|
| `3 / 5` | 你拥有的 5 个角色里已送完 3 个 |
| 未拥有角色 | 这个套装需要的角色你一个都没有 |
| 已完成 | 你拥有该套装全部角色，且全部送完 |
| 已送完 | 你拥有的角色都送完了，但还有角色没拥有 |

已完成 / 已送完的套装配深色描边并整体变淡。

展开后点角色格切换完成状态。**点未拥有的角色会提示你先去上面勾选。**

### 筛选与搜索

支持按套装名 / 角色名搜索，以及地区、室内外、状态三个下拉筛选。

筛选里的「未完成」只包含**有角色但没送完**的套装，不含「未拥有角色」的那些。

### 底部按钮

「重置全部数据」在页尾固定区，会清空拥有的角色和所有完成记录，需二次确认。

<a id="save" name="save"></a>
## 💾 数据保存

### 数据存在哪

**全部存在你这台设备的浏览器里**（`localStorage`），不会上传到任何服务器，也不会跨设备同步。

| 内容 | 存储位置 |
|---|---|
| 游逸旅闻完成记录 | 本机浏览器 |
| 游逸旅闻 UID | 本机浏览器 |
| 拥有的角色 | 本机浏览器 |
| 套装完成记录 | 本机浏览器 |
| 赠礼套装 UID | 本机浏览器 |

### 备份与迁移

**导出**：点「导出」按钮，会下载一个 JSON 文件，文件名形如：

```
游逸旅闻存档记录-123456789-20261103.json
赠礼套装存档记录-123456789-20261103.json
```

填了 UID 会带在文件名里，方便区分账号。

**导入**：点「导入」按钮，选择之前导出的 JSON 文件。导入会**覆盖**当前记录。

> 换手机、换浏览器、重装系统之前，务必先导出一份。

### 导入兼容

游逸旅闻的存档兼容三种旧格式：

- 现在的三段式：`角色名·版本·旅闻名`
- 旧的两段式：`角色名·旅闻名`（会匹配所有同名旅闻）
- 更早的数字 id 列表

赠礼套装导入时会校验格式，不匹配的会直接提示失败而不会写入。

### 会丢数据的情况

- 清理浏览器缓存 / 站点数据
- 使用无痕模式（关闭窗口即清空）
- 手动「清空全部记录」或「重置全部数据」

<a id="faq" name="faq"></a>
## ❓ 常见问题

**Q：记录会同步到我的游戏账号或米游社吗？**
不会。本工具只在本机浏览器里存一份数据，不联网、不登录、不采集任何信息。

**Q：换手机了，进度怎么办？**
先在旧设备导出 JSON，在新设备打开站点后点「导入」选中该文件。

**Q：为什么有些旅闻标题是红色的？**
那表示它属于游戏内的隐藏成就。可以用「类型 → 隐藏」只看这些。

**Q：「已完成」和「已送完」有什么区别？**
- **已完成**：这个套装需要的角色你**全部拥有**，并且都送完了
- **已送完**：你拥有的角色都送完了，但套装里还有角色你**没有**

前者是真的收工，后者是「能做的都做完了，等抽到剩下的角色再说」。

**Q：推荐套装为什么只给 5 个？**
它回答的是「现在最值得先做哪几个」，不是完整清单。完整列表在下面的「全部套装」里。

**Q：能不能只看没做完的旅闻？**
可以，「状态 → 未完成」。

**Q：页面地址能分享吗？**
可以。每个页面有独立地址，例如 `…/adventurer-handbook/#/tales`、`…/#/gift-set`，但**记录本身不会跟着链接走**，只在你自己的设备上。

**Q：两个编辑器在哪？**
那是维护数据用的内部页面，不在导航里、页面上也没有入口，只能直接输入地址打开：

- 游逸旅闻编辑器 → `…/adventurer-handbook/#/tales-editor`
- 尘歌壶赠礼套装编辑器 → `…/adventurer-handbook/#/gift-set-editor`

普通使用不需要管它们。

## 🗂 项目结构

只到文件夹一层，具体文件不列出。

```text
adventurer-handbook/
├── .github/
│   └── workflows/            自动构建与部署
├── public/
│   └── data/                 游戏数据 · 运行时加载，不参与编译
└── src/
    ├── components/           可复用控件：按钮、输入框、下拉、弹窗、通知等
    ├── composables/          跨组件共享逻辑：主题、通知队列、数据加载
    ├── icons/                图标字典
    ├── styles/               设计令牌与全局基线样式
    └── views/                首页 + 两个工具页 + 两个编辑器
```

三条需要知道的规则：

- **`public/` 下的内容原样发布，不经过编译。** 所以换版本号、加旅闻、改套装数据，只需要更新 `public/data/`，不用重新构建。
- **`public/data/` 里的文件由两个编辑器生成** —— 编辑器导出 `data.js` 后，覆盖到对应路径即可。
- **根目录只放构建配置**，没有业务代码。
